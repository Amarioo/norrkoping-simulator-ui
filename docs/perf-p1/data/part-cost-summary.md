# Phase P1 — cost per part (hide one part / skip one job)

Phase P1 part cost: hide one part (or skip one CPU job) and compare with the unchanged scene measured right before and after (baseline = mean of the two), 300 frames each, fullscreen 2560x1440, hook build, Edge headless uncapped, DPR 1, Europe/Stockholm 2026-10-21, stadium off. Traffic off = /api aborted. Variant order rotates per round.

Host: AMD Ryzen 7 9800X3D 8-Core Processor, 16 threads. Rounds: 3. Machine load before each round (whole machine, all cores): 17 %, 16.2 %, 16.6 %, 17.2 %, 17.3 %, 19.8 %.

Δ = variant − baseline of the same page (negative = the part costs that much). Shown: median over rounds, then the range (min … max) over rounds. Mean = mean frame interval; p95 = 95th percentile of the frame interval; CPU = Threlte tasks + renderer.render() per frame.
