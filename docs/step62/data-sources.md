## Acquisition requests ready to send later

Contact **Kontakt Norrköping**, 011-15 00 00 / `kontakt@norrkoping.se` ([official contact route](https://norrkoping.se/boende-trafik-och-miljo/lantmateri-och-kartor/norrkopingskartan-noka)), asking referral to GIS/Samhällsbyggnadskontoret and street/park lighting asset management. For reserve/trails the current reserve page lists `samhallsbyggnadskontoret@norrkoping.se`. Do not send a request without the user's instruction.

Request a bounded EPSG:3006/RH2000 GeoPackage/CSV export of **lighting points and luminaires**, stable IDs, owner, pole/suspension/wall mount, actual head offsets, mounting heights, tilt/azimuth conventions, fixture model, flux/CCT/photometry if available, switching/dimming groups, installation/removal/inspection dates, bridge/underpass/station/park fixtures and explicit unlit areas. Include city clip polygon above; ask for a 2026 reference date and field-level uncertainty. Ask for both infrastructure and applicable time-control documents; public opening hours are insufficient.

For Vrinnevi request the **named 2.4 km `kof_motionspr` feature**, full ordered polyline, entrances, current reserve boundary and maintained clearings; verify whether 2.5 km is rounded, and obtain pole points/operating rules. Ask for native CRS declaration if EPSG:3006 export unavailable. Request an explicit licence allowing adaptation and redistribution with the simulator; until granted, record `redistribution=unknown` and keep source geometry out of Git/runtime.

For national road/rail assets use the appropriate Trafikverket data channel after selecting the actual dataset/licence. For airport electrical layouts/fixture coordinates, obtain airport-operator permission and a dated drawing. AIP does not provide an electrical installation survey. Obtain dated, permission-compatible facade/sign photographs for both police sites, post-renovation town hall and fuel canopies.
